# tools/ — локальний пайплайн підготовки даних

Запуск: `npx tsx tools/<name>.ts`. Типи — з `src/types.ts`. Формат YAML і JSON — `docs/DATA.md`.
Перевірка типів: `npx tsc --noEmit -p tools`.

## Порядок

1. `fetch-osm.ts` — раз (або коли треба оновити): Overpass → `data/osm/roads.json`, `data/osm/pois.geojson` (bbox Хмельницького). Відповіді кешуються в `data/cache/`.
2. `find.ts` — допомога при оцифруванні:
   - `find.ts "А" "Б"` — перетини двох вулиць (спільні вузли, інакше найближчі точки до 40 м);
   - `find.ts "А"` — варіанти назв, bbox, кінці, точки кожні ~300 м, oneway-ділянки, вулиці, що перетинають;
   - `find.ts --near <lat> <lng> [radiusM=80]` — найближчі дороги й перехрестя.
   Точний збіг назви має пріоритет над підрядком; «вулиця/проспект/вул.» ігноруються.
3. `build-route.ts <id> | --all` — `data/routes-src/<id>.yaml` → `public/data/routes/<id>.json` + звіт перевірок (довжина vs офіційна, відстань до ТСЦ, притягування точок OSRM, підозрілі розвороти, streets, POI).
4. `preview-route.ts <id> [--out f.png] [--zoom-to <fromM> <toM>]` — PNG 1600×1100 у `data/preview/` (потрібен інтернет для тайлів OSM).
5. `build-index.ts` — `centers.json` і `centers/<id>.json` з `data/centers-src.yaml` і наявних `routes/*.json`.

Інше: `sign-map.ts` — мапа кодів `traffic_signs=UA:…` → ПДР; `lib.ts` — спільне (кеш, геометрія).

## Як працює build-route

- OSRM (`router.project-osrm.org`, запас — `routing.openstreetmap.de`), `continue_straight=true`; у точках `uturn: true` запит розбивається й геометрії склеюються.
- Спрощення (`@turf/simplify`, 0.00002, highQuality) виконується окремо для кожного відрізка однієї вулиці, тож межі `streets` лишаються точними. Безіменні відрізки < 20 м приєднуються до сусіда.
- POI: з `pois.geojson` у 15 м від лінії; вузли, що лежать на дорозі з `roads.json`, — лише ≤ 6 м і якщо дорога йде паралельно маршруту (|cos| ≥ 0.5); `direction=forward|backward` для give_way/stop враховується; зупинки — лише праворуч за ходом; окремий POI на кожен прохід (>100 м); дублікати одного типу < 12 м зливаються; в'їзд на `junction=roundabout` → `roundabout`.

## Відомі обмеження

- Публічні OSRM/Overpass/Nominatim можуть тимчасово падати; кеш у `data/cache/` рятує повторні запуски (щоб примусово оновити — видалити файл кешу).
- OSRM не знає тимчасових обмежень і не дає вибирати смугу; на дорогах з розділювачем точку ставити на потрібний бік.
- Опорна точка, віддалена від дороги (напр. сам ТСЦ ~30 м), притягується до найближчої дороги — це нормально, але дивіться попередження > 25 м.
- Напрям `give_way`/`stop` без тегу `direction` не перевіряється. Знаки `traffic_sign=*` розпізнаються лише з `sign-map.ts`.
- Евристика «підозрілих розворотів» (зміна курсу > 150° на < 40 м) може пропустити розворот широкою петлею.
- Коди ПДР у `pdr-signs.json` (особливо 5.38.1, 5.45.1, 1.11 для штучної нерівності) варто звірити з чинним текстом розділу 33.
