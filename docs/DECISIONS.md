# Рішення

Усі рішення приймає лід (Claude Fable 5.2) автономно й записує тут.

## 2026-11-10

- **Модель.** Сесія працює на Claude Fable 5.2 (`claude-fable-5-2`). Сабагенти запускаються з `model: sonnet` (Sonnet 5.5).
- **Оточення.** Windows 11, git 2.55, node 24.22, npm 11.19, gh 2.103 (акаунт `asdevius-ai`) — усе було, нічого не встановлював.
- **Сон комп'ютера.** `powercfg` НЕ міняв: зміна системних налаштувань живлення — поза тим, що мені дозволено робити. Замість цього ввімкнув вбудоване утримання від сну застосунку Claude (діє, поки сесія активна; налаштувань системи не змінює). Повертати у фіналі нічого не треба.
- **Ліміт.** План Pro. У десктопному застосунку є інструмент `get_usage` — він віддає 5-годинний, тижневий і тижневий Fable ліміти. Це основне джерело. Статус-рядок (`.claude/statusline.mjs`) і хук (`.claude/hooks/usage-guard.mjs`) створені й підключені; оскільки статус-рядок у десктопі може не запускатись, я сам записую значення з `get_usage` у `.claude/usage-state.json` через `tools/usage-write.mjs`, тож хук працює в обох випадках. Пороги: 80% — не починати нове, 85% — чекпоінт.
- **Назва.** Застосунок — «Вираж», репозиторій — `virazh` (вільний в акаунті). Стиль свій: темна тема, бурштиновий акцент.
- **Завантаження схем.** `hsc.gov.ua` (Akamai) віддає 403 на curl і headless Chromium. Схеми завантажені через вбудований браузер застосунку як звичайні завантаження (20 файлів `.tmp` лишилися в теці «Завантаження» — їх можна видалити) і скопійовані в `data/raw/6841/`. Адреси файлів на сторінці не змінились.
- **Контракт.** POI і сегменти вулиць вбудовані у файл маршруту (`Route.pois`, `Route.streets`) — один запит на маршрут. Додано `RouteMeta.number`, `CenterSummary`, `PdrSign`.
- **Категорія.** На схемах усі маршрути спільні для категорій B, C1, D1, D, BE, C1E, D1E, DE — беремо рядок зі схеми.
