# Контракт даних

Типи — у [`src/types.ts`](../src/types.ts). Це єдине джерело правди; `tools/` імпортує типи звідти.

## Файли, які читає сайт (`public/data/`, комітяться)

| Файл | Тип | Хто пише |
|---|---|---|
| `centers.json` | `CenterSummary[]` | `tools/build-index` |
| `centers/<centerId>.json` | `Center` | `tools/build-index` |
| `routes/<centerId>_<n>.json` | `Route` | `tools/build-route` |
| `pdr-signs.json` | `PdrSign[]` | вручну (Агент A) |

Сайт вантажить їх через `import.meta.env.BASE_URL + 'data/...'`.

Правила:
- координати — `[lng, lat]`, 6 знаків після коми;
- відстані — цілі метри від старту маршруту;
- `Route.pois` відсортовані за `distanceAlongM`; `coord` лежить на лінії;
- `Route.streets` покривають `[0, lengthM]` без дірок і перекриттів, сусідні відрізки з однаковою назвою злиті;
- `Route.lengthM` — довжина саме збереженої (спрощеної) геометрії, порахована turf `length`;
- `verified: false` → сайт показує позначку «чернетка».

## Джерела маршрутів (`data/routes-src/<centerId>_<n>.yaml`, комітяться)

Пише лід (оцифрування), читає `tools/build-route`.

```yaml
id: "6841_1"
number: 1
name: "Маршрут №1"
category: "B, C1, D1, D, BE, C1E, D1E, DE"
sourceImage: "6841_1.jpg"
officialLengthKm: 17        # з офіційної схеми, для перевірки правдоподібності
verified: false
notes: ""                    # необов'язково
streets:                     # перелік вулиць зі схеми, лише довідково
  - "вул. Західно-Окружна"
waypoints:                   # впорядковані опорні точки; маршрут будується ЧЕРЕЗ них по дорогах
  - { lat: 49.4101, lng: 26.9502, note: "старт, ТСЦ" }
  - { lat: 49.4120, lng: 26.9310, uturn: true, note: "розворот" }   # uturn: тут дозволено розворот
  - { lat: 49.4101, lng: 26.9502, note: "фініш" }
```

- Точок може бути багато (20–60): вони «прибивають» маршрут до потрібних вулиць.
- Точку ставимо на потрібній смузі/проїзній частині (для доріг із розділювачем — на правильному боці).
- `uturn: true` — у цій точці маршрут розвертається; в усіх інших розвороти вважаються артефактом.

## Центри (`data/centers-src.yaml`, комітиться)

```yaml
- id: "6841"
  name: "ТСЦ МВС № 6841"
  city: "Хмельницький"
  address: "вул. Західно-Окружна, 11/1"
  coord: [26.9502, 49.4101]
  routeCount: 20
```

## Локальні дані (не комітяться)

- `data/raw/<centerId>/<centerId>_<n>.jpg` — офіційні схеми;
- `data/osm/` — вивантаження Overpass (дороги, POI);
- `data/cache/` — кеш мережевих запитів;
- `data/preview/` — PNG-прев'ю маршрутів.
